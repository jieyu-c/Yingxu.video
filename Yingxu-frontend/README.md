# 映序AI 前端

Vue 3 + TypeScript + Vite 前端工程，包含官网、登录页和注册页。工作台暂未实现。

## 本地运行

```bash
npm install
npm run dev
```

运行 `npm run build` 可进行 TypeScript 检查和生产构建。

## 当前范围

- 官网：产品介绍、创作流程、页面内成片放映厅、五幅创意灵感画廊、常见问题和注册入口。
- 官网成片演示：页面内放映厅支持三种作品类型切换；首屏“观看案例”会滚动至该区域。目前没有真实成片素材，界面明确显示“成片视频待接入”。
- 创意画廊：五张主题封面展示页面视觉方向，不代表实际可播放成片；素材就绪后再接入视频。
- 登录/注册：响应式表单、模式切换、基本校验与状态反馈。
- 账号接口尚未连接；验证码发送接口在现有后端仍为空实现，因此页面不会伪装为已发送短信或已登录。
- 页面中的用户协议和隐私政策目前是待补充文案，正式上线前需替换为真实内容。

视觉素材位于 `src/assets/`，来源于本项目选定的映序AI设计稿。

## 接入成片视频

在 `src/components/ShowcaseTheater.vue` 顶部的 `demos` 数组中，为每个示例填写 `src` 视频地址；封面由对应的 `poster` 字段指定。建议使用有授权的 MP4（H.264）或 WebM 成片。接入后，页面内放映区会提供播放控制，无需弹窗。默认官网背景图不变。
